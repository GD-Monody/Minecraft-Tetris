# 技术方案 v0.1

2026-10-25。对应设计规格 v0.1。

## 引擎与管线

- Unity 2022.3.62f3c1（你装好的版本）
- 内置渲染管线，不装 URP。URP 要从 Package Manager 联网拉包，先把这条依赖去掉
- C# 脚本，单场景起步
- 输入用内置 Input Manager，不装新 Input System，同样是少一个联网依赖

## 场景结构

场景里一个 GameRoot，下面挂：

- GameManager：状态机、游戏循环
- Board：场地数据、消除判定
- Spawner：生成下一块
- CameraRig：轨道相机
- EffectsRoot：MC 效果的挂载点
- UIRoot：界面

## 数据模型

- 场地用三维数组存，下标 [x, y, z]，值是方块类型枚举，空白为 None
- 方块形状用三维 bool 数组描述，包围盒最大 4×4×4
- 方块类型：平面 7 种 I、O、T、S、Z、J、L，加后续的立体块
- 每个方块带一组"方块类型到贴图"的映射，贴图来自 `_refs/mc_textures_26.2`

## 坐标与方向

- y 轴是下落方向，0 在底部
- 场地边界由设置里的 x、y、z 决定
- 相机看向场地中心

## 游戏循环

状态机：主菜单 → 游戏中 → 暂停 → 结束

游戏中每一帧：

1. 读输入
2. 当前方块按重力下移一格
3. 碰撞检测，撞了就锁定
4. 锁定后结算：检查消除、执行消除、上方下落
5. 结算后调用效果接口（当前为空实现）
6. 需要时生成下一块

## 消除

- 行消：遍历所有 (y, z) 组合，某一行 x 方向全部填满就消
- 层消：遍历所有 y，某个高度层的 x × z 全部填满就消
- 消除后上方整体下落补位

两种模式在设置里切换，规则逻辑各自独立，别写成一个带分支的大函数。

## MC 效果接口

定义 `IBlockEffect`，四个实现先留空：

- `SandEffect`：沙子下落
- `TntEffect`：TNT 爆炸
- `GlassEffect`：玻璃压碎
- `WaterLavaEffect`：水 + 岩浆成石

接口方法先定成占位（比如 OnCellLocked、OnLinesCleared、OnTick），具体签名到实现阶段可能还要改，这里只保证调用点存在。

### 之后想加的方块效果（先记录，不实现）

- 基岩：不随消除下落；设置里开关它是否进入方块池
- 各种类型的原木：锁定后会在周围生成树叶
- 傀儡：雪傀儡、铁傀儡、铜傀儡在对应方块加南瓜头时生成，消除对应方块，然后变成模型安置在场地外的固定位置
- 结构方块：锁定后记住当前结构，被消除后还原当时记住的结构
- TNT：红石块接触后激活爆炸
- 沙砾：和沙子一样下落

## 渲染

- 每个格子一个 Cube，材质用对应贴图
- 默认 10×20×1 是 200 个格子，对象池复用
- 可调上限 20×40×10 是 8000 个，直接铺 8000 个物体性能会掉，到时候要么合并网格，要么只渲染可见面
- 方块下落用 transform 位移做，不做逐格跳动

3D 版本每个方块要六面贴图。已经从 26.2.jar 里按方块模型 json 解析出来了，清单在 `_refs/方块贴图清单.md`，共 51 张，覆盖 22 种方块、9 种原木变体，水和岩浆单列。

## 素材导入

- 贴图全部 16×16，Filter Mode 设 Point (no filter)，压缩关掉，像素风放大不糊。
- 方块贴图打一张图集，方块各面 UV 指向图集里的格子。材质少、能合批，改某张贴图重打一次图集就行，不用动方块配置。
- 图集用脚本拼接：8 列、每格 16×16，当前 51 张排成 8×7 格，输出 128×112（`tools/build_atlas.py`）。源图保持单文件、单命名，替换后重跑脚本。
- 音效映射：
  - 方块放置：place_stone、place_wood、place_glass，按方块材质选
  - 单行或单层消除：pickup_xp
  - 多行或多层消除：levelup
  - 界面点击：click
  - TNT：fuse 点燃、explode 爆炸（阶段 4 才用）

## 相机

- CameraRig 用轨道式：yaw、pitch、距离三个参数
- 鼠标拖拽改 yaw 和 pitch，滚轮改距离
- 透视还是正交待定，倾向透视，3D 感更强

## 输入

- 抽一层 `IInputSource`：MoveX、MoveZ、SoftDrop、HardDrop、RotateCW、RotateCCW、Pause
- 键盘实现先做，触屏实现后补
- Windows 默认键位：
  - A / D 或 ← / →：左右移动
  - W / S 或 ↑ / ↓：前后移动（z 轴）
  - 空格：硬降
  - Shift：软降
  - Q / E：旋转
  - Esc：暂停
- 键位自定义：每个动作存一个 KeyCode 映射（左右、前后、软降、硬降、顺逆旋转、暂停），设置里改，存 PlayerPrefs，改完立即生效。实现上不依赖 Input Manager 的轴，直接用 `Input.GetKey(KeyCode)` 查映射表，运行时改键才真的有效。

## 阶段计划

1. 工程骨架：场地生成、一个方块能落下来
2. 完整俄罗斯方块玩法：移动、旋转、消行、计分、结束
3. 3D 场地：z 轴生效、前后移动
4. 立体块：z ≥ 2 解锁
5. MC 效果：按沙子、TNT、玻璃、水岩浆的顺序逐个实现
6. 相机、UI、设置
7. 跨平台：WebGL、Android

## 风险

- 8000 格上限的渲染性能
- 立体块加三轴旋转后的碰撞和旋转踢墙
- WebGL 的纹理和内存限制
- 手机触屏操作的手感
