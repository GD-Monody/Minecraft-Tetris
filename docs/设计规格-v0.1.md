# 我的世界俄罗斯方块 3D 版：设计规格 v0.1

2026-10-25 初稿。这一版是给马克杯 2022 年的 TetrisM 做升级：保留 MC 方块外观和方块特性，场地换成真正的 3D 网格。

2026-10-27 修订：补「水 + 岩浆成石」的完整规则（黑曜石 / 原石），MC 方块特性章节按实际实现更新。文件名保留 v0.1。

## 场地

- 3D 网格：x 宽、y 高、z 深
- 默认 10 × 20 × 1，三个轴都在设置里调
- 初版可调范围：x 5~20，y 10~40，z 1~10
- 方块沿 y 轴下落，底部是地板
- 相机绕场地中心轨道旋转，上下左右都能看，滚轮或双指缩放

## 方块

- 每个方块由 4 个立方体组成
- 平面块 7 种：I、O、T、S、Z、J、L。z = 1 时就是原版俄罗斯方块的玩法
- 立体块：z ≥ 2 才进入生成池，形状待定
- 生成用 7-bag 随机（标准和原版一致）
- 移动：左右（x）、前后（z）
- 旋转三套，对应屏幕上三根轴，各两个方向，可以任意叠加：
  - **面内旋转**（绕屏幕法线）：方块贴着玩家那个平面里转，方块始终正对玩家（原版俄罗斯方块的转法）
  - **俯视旋转**（绕竖直轴）：整块转过去朝别的方向。
  - **前后翻**（绕水平轴）：往背面倒 / 往正面翻，方块躺平或竖回来。
    后两种会改变方块在深度方向占的范围，z = 1 的场地转不动，只在 z ≥ 2 时有用
- 三组旋转叠加以后是完整的 24 种朝向（立方体的全部旋转），不再有"转到某个角度就转不动"的死角
- 1 格厚的平面块绕 x 轴翻 90° 时，"1×1 截面"的 I 型看起来形状不变（只有贴图转了方向），这是几何上的必然
- 下落：自动下落、软降、硬降。自动下落的速度可调，倍率范围 (0, 2]，
  1 = 标准（0.8 秒一格）。3D 场地（z > 1）要前后找落点，1 倍速常常来不及，所以这项必须开放
- 落地后有短暂锁定延迟，期间还能移动和旋转

## 消除

两种模式，设置里切换：

1. 行消：某个深度层的某一行（x 方向）填满，这一行消失
2. 层消：某个高度层的整个平面（x × z）填满，这一层消失

消除后上方方块下落补位。

### 沙子下落

- 会掉的方块：沙、红沙、沙砾、可疑的沙、可疑的沙砾、各色混凝土粉末
- 落定后一直往下掉到踩实为止，掉落不扣分、不消耗回合
- 落定发生在方块写进场地之后、满行判定之前——刚落下的沙子可能正好把下面补满，顺序反了会漏消

### 水 + 岩浆成石（2026-10-27 定稿）

**产物规则**（照 MC 原版的方向，用本项目的「份数」模型表达源与流动）：

- 岩浆格**满格**（8/8 份，等于岩浆源）遇到水 → **黑曜石**（obsidian）
- 岩浆格**不满格**（流动岩浆）遇到水 → **原石**（cobblestone）

**判定**：

- 只看**六向相邻**：上、下、左、右、前、后。斜对角不算。
- 谁主动不区分：水往岩浆流、岩浆往水流，只要相邻就反应，变的是**岩浆那一格**。
- **同一格**也算相遇：水方块落进岩浆那格（或反过来）当场结晶，不会出现"后落的那种把先落的覆盖掉"。

**产物是什么**：

- 是固体方块：写进场地网格，会挡住后面的方块和水、能参与满行判定、被消除时照常下落。
- 它自己不会像沙子那样下落。

**水的去向**：

- 参与反应的水**整格被消耗**，不管那格有几份。
- 这条是为了让场地里的水只减不增：否则水会越灌越多，最后把场地填死。

**连锁**：

- 水多的时候会继续往岩浆那边流，能连着把一片岩浆一块块吃掉。
- 先变出来的石头会挡住后面的水，所以"一次全部反应完"不会发生，看起来是逐块结块。

**节奏**：

- 反应和流动共用一个 tick（0.1 秒）。反应在流动之前做，所以刚生成的石头当 tick 就能挡水。
- 一个 tick 内所有相遇的格子都会处理，不排队、不延迟。

**待补**：

- ~~音效~~ 已补：`random.fizz`（水浇灭岩浆的嘶声），从 26.2 资源库提取。

### TNT 引爆（2026-10-28 定稿）

**怎么拿到**：TNT 不进普通随机池，作为「道具」放在特殊池里（每 12 个方块抽一次特殊池，
其中水 30% / 岩浆 20% / TNT 20% / 沙类 30%）。**抽到 TNT 之后，下一块必定是红石块。**

**怎么点着**：TNT 和红石块**六向相接**（上 / 下 / 前 / 后 / 左 / 右，含同格）就点火，和原版一致。
一次落定后全场扫一遍，所以「新放的红石凑上旧 TNT」和「新放的 TNT 凑上旧红石」都算。

**引信**：2.4 秒（原版 4 秒，这里一局太快）。燃烧期间方块白闪，节奏照原版：
**0.25 秒白 / 0.25 秒原色**（原版 `TntRenderer` 是每 5 tick 换一次贴图），燃烧期间占着格子。

**爆炸**：球形范围，半径 2 格。

- z = 1 的场地上是半径 2 的圆，约 13 格；场地深到 z ≥ 2 才炸出完整的一团。
- 范围内所有方块都炸掉（包括红石块本身），范围内的水 / 岩浆一起吹掉。
- 范围内的其它 TNT 不直接消失，而是被点着（0.18 ~ 0.55 秒短引信），形成**连锁**。
- 炸掉一格得 4 分（清一行是 100 分，炸一圈差不多半行的收益）。
- 弹坑上方的沙子 / 沙砾会立刻塌下来。
- **原版 TNT 炸不掉的方块，这里也炸不掉**：基岩、黑曜石、哭泣的黑曜石。
  它们在原版的爆炸抗性是 3600000 / 1200，而 TNT 威力只有 4，所以原版也炸不动。
  被保住的格子不计分。空格里的水 / 岩浆照旧被吹掉（原版 TNT 能把水炸开）。

**被消行带走**：燃烧中的 TNT 如果被消行挪了位置 / 消掉，这颗就哑火，不会在原地炸。

**表现**：`random.fuse` 引信声 + `random.explode1~4` 爆炸声、镜头震动、碎块粒子。

### 原木长树叶（2026-10-28 定稿）

原版里原木不长树叶（树是世界生成时整棵出现的），这是本项目的自创规则：**原木落定后在它周围长树叶**。

- **哪些原木**：自然原木（`*_log`）和六面树皮的「木」（`*_wood`）。
  **剥皮原木不长**（树皮都剥了），**菌柄 / 菌核不长**（菌类没有树叶），竹块不长。
- **长什么**：同树种的树叶，橡木 → 橡树树叶，云杉 → 云杉树叶……共 9 种：
  橡树 / 云杉 / 白桦 / 丛林 / 金合欢 / 深色橡树 / 红树 / 樱花 / 苍白橡树。
- **长哪**：木头正上方、斜上方一圈、同一层的四个侧面（共 13 个候选位），
  只长在空格里，有水的格子不长。位置随机，不会总朝同一边。
- **长几片**：一个原木格长一片，一次落定最多 6 片。
- **果实性**：树叶是普通方块——挡方块、能凑满行、能被消除、跟着存档走；
  不会自己凋落，也不会再长出新树叶。
- **配比**：树叶不进随机材质池，也就是说不会有「一整块树叶」的方块掉下来，它是木头长出来的。

### 基岩不随消除下落（2026-10-28 定稿）

**基岩消除时钉在原地不动，但自己所在的行被消掉时照样消失**——这是本项目的自定义规则
（原版基岩是不可破坏的，消行也不会跟着掉）。

- **怎么表现**：消行 / 层消之后，基岩停在原来的格子上；它上面那一摞方块停在基岩上面，
  不跟着一起往下走。基岩下面那一格会**永久空着**——那一列从此填不满满行，
  这是「钉住」的代价。
- **它自己能被消**：基岩所在的那一行被判定为满行时，基岩跟那一行一起消失。
- **挡东西**：基岩是实心方块，沙子落到它上面会停住，石头落在它上面会叠着。
- **配比**：默认**不进方块池**，也就是说正常游玩不会遇到基岩。
  设置里打开「基岩进池」之后，它占特殊池的 15%（大约每 100 个方块里有 1 个是基岩）。
  理由是它掉下来就是一根永久柱子，纯增难度，不该默认塞给玩家。

### 结构方块的记忆与还原（2026-10-28 定稿）

**结构方块落定时记住周围一片的构造，被消掉时把记住的构造还原出来，还原完自己消失。**

- **记住什么**：以结构方块为中心的 **3×3×3** 范围（z=1 的场地上就是 3×3 平面，9 格；
  场地深到 z ≥ 3 才是完整的 27 格）。记的是**绝对坐标**的方块，不记流体。
- **什么时候记**：结构方块落定的瞬间（和方块写进网格是同一帧）。
- **什么时候还原**：它自己所在的那一行 / 那一层被消掉，或者被 TNT 炸掉。
- **还原的过程**：先把那一片**整体清空**，再按记忆**一格一格搭回来**（每 0.06 秒一格，
  9 格约 0.5 秒），搭完之后结构方块自己消失。
- **同时触发多个**会排队，一次还原一个。
- **副作用**：还原是绝对坐标的，不管中间发生了什么，那一片都会恢复成记忆时的样子；
  消行把上方搬下来之后，还原会把搬动过的那片覆盖回去。还原期间玩家还能操作，
  新放下去的东西可能被覆盖。
- **配比**：默认**不进方块池**（和基岩一样是道具），设置里开「结构方块进池」之后
  占特殊池的 10%。

### 之前想留的接口方案（已废弃）
原计划定义 `IBlockEffect` 加四个空实现，把效果做成可插拔的。实际做的时候发现效果和主循环耦合很紧（沙子必须在写网格之后、判满行之前跑；流体要和 Grid 双向通信），套一层接口只是多绕一圈，最后写成 `Gravity` 和 `Fluids` 两个静态类，直接在 `GameLoop.LockPiece` / `Tick` 里调用。`Assets/Scripts/Effects/` 目录留着没删，将来 TNT 那种独立性强的效果可以还做成组件挂进去。

## 操作（PC）

- A / D 或 ← / →：左右移动
- W / S 或 ↑ / ↓：前后移动（z 轴）
- 空格：硬降
- Shift：软降
- Q / E：面内旋转（逆 / 顺时针，绕屏幕法线）
- Z / C：俯视旋转（逆 / 顺时针，绕竖直轴）
- V / R：前后翻（往正面 / 往背面，绕水平轴）
- 鼠标拖拽：转视角
- 滚轮：缩放
- Esc：暂停
- 设置里可以自定义键位，改完立即生效

手机后续做屏幕虚拟键加拖拽转视角。

## 界面

- 主界面：开始、设置、退出
- 游戏界面：场地、下一块预览、分数、等级、暂停
- 设置：场地尺寸（三个轴）、消除模式、下落速度、音乐音量、键位、音效

### 视觉风格

- **字体：方正字迹-龙吟体 简**（毛笔行书）。界面上的中文全是这个字体，包括标题、按钮、HUD 文字、
  方块名。英文 / 数字也走同一套字形，保证风格统一
- **字号整体放大到 1.25 倍**，由 `UiSkin.TextScale` 一个常量控制，布局尺寸一起等比放大。
  默认窗口 1440×900 下最大的面板（按键设置）高 838px，塞得进去；想再放大记得同步检查这一条
- **主菜单按钮再单独放大**，目标是当下的 2 倍（`UiSkin.MenuScale = 2f`）。屏幕装不下时自动降一档：
  1440×900 五个按钮实到 1.53 倍（535×84，字号 34），六个按钮 1.27 倍；1920×1080 五个按钮约 1.98 倍。
  按钮上的字跟着按钮一起长，不会出现「框大了字没大」
- 底部署名文案是「AGENTS辅助完成」
- **光标带深蓝色荧光拖尾**：尾部长约 0.28 秒，靠近光标是亮蓝白的内芯，越往后越散越淡；
  光标本身有一圈缓慢呼吸的外光晕
- 配色沿用 MC 风深色半透明面板 + 灰白细边框，强调色是草绿 `#85C74C`

## 音频

- **背景音乐**：MC 原版的 14 首常速曲（Sweden / Minecraft / calm1~3 / hal1~3 / Haggstrom /
  piano1~3 / nuance1~2）+ 2 首菜单曲（menu1 / moog_city_2），从本机正版资源里提取，
  `tools/extract_music.py` 可重跑。共约 28 MB，按流式导入（不整首解码进内存）
- **播放方式**：洗牌袋随机——一轮里每首各放一次，不会连着放同一首；两首之间留 10~24 秒静默，
  开头淡入、结尾淡出。标题界面用菜单曲库，进游戏换成常速曲库，切界面时淡出当前这首
- **设置**：音乐音量 0~100%，0 = 关，默认 45%；按 Esc 暂停时音乐一起暂停
- **音效**：放置音按 MC 材质分组（60 组 / 281 个变体），另有消行、结晶、TNT 引信与爆炸
