# SUBSTRATA —— 去 IP 化重制计划

> 分支：`original`（从 `main` 拉出，不动 `main` / `web` / `android`）
> 目标：做一版**不含任何 Minecraft / 俄罗斯方块 素材与名称**的游戏，代码骨架保持不变。

---

## 一、名字

**Substrata**（/sʌbˈstrɑːtə/，读作“萨布斯抓塔”）

- 词义：底土层、下层基岩；复数，天然带“一层层叠起来”的意思
- 副标题建议：*a substrata puzzle*（英文商店页）/「一层层往下挖的方块解谜」（中文）
- 产品名（PlayerSettings.productName）：`Substrata`
- 包名：`com.monody.substrata`（安卓）/ 窗口标题同名
- 为什么合适：不碰「我的世界」「俄罗斯方块」「Tetris」，且正好对应游戏的核心机制——
  3D 深度、层次俯视图、重力方块沉底

---

## 二、保留 / 砍掉的机制

机制本身（重力、流动、燃烧、爆炸）属于**自然物理现象与通用玩法**，不受版权保护，可以留。
受保护的是**具体名称与美术表达**。

| 机制 | 处置 | 备注 |
|---|---|---|
| 水流动、填满空腔 | 保留 | 改名为「流」、「涌泉」之类 |
| 岩浆流动、遇水凝固 | 保留 | 凝固产物换个名字（不用「黑曜石」） |
| 易燃物被点燃、火焰蔓延 | 保留 | |
| 重力方块下落（沙、砾石） | 保留 | |
| 爆炸（引信、连锁） | 保留 | 「TNT」这个名字要换 |
| 红石电路、活塞、侦测器 | **砍掉** | 我们没有电路模拟，只是贴图 |
| 附魔、酿造、合成台 | **砍掉** | 从未实现，只是装饰方块 |
| 下界 / 末地专有方块 | **砍掉** | 同上 |
| 苦力怕、末影人等生物命名 | **改名** | 专有名词 |

## 三、资源改造

### 1. 方块贴图（主要工作量）

- 现状：354 种方块，统一在一张**图集**里（`BlockCatalogData.AtlasColumns/Rows`，16×16 像素/格，
  由 `tools/build_full_atlas.py` 生成），代码只认 id 与图集坐标。
- 计划：
  - 砍到 **60～80 种**（现有 354 种里有大量 16 色变体），按「材质 × 颜色」程序化生成；
  - 另写 `tools/build_original_atlas.py`，全部自绘（代码画像素，不引用任何第三方图）；
  - 保留 16×16 / 32×32 由生成器的 `TILE` 参数决定，图集行列数自动算。
- **存档影响**：存档里存的是方块 id，数量一改旧档就错位。处理方式：新版本检测旧档 →
  提示「旧存档来自旧版本，已重置」，不尝试映射（映射只对纯重命名有效，砍数量就无效了）。

### 2. 音效

- 现状：61 组 clip（`BlockSfxData` 里配），全部来自 MC。
- 计划二选一：
  - **A. 程序合成**（推荐）：噪声 + 包络 + 滤波，方块撞击音本来就适合合成，零授权风险；
  - **B. CC0 素材**：freesound / OpenGameArt 筛 CC0，不能选 CC-BY（要署名）或 NC（禁商用）。

### 3. 字体

- 现状：方正字体（商用需授权）。
- 换成 **思源黑体（Source Han Sans，OFL）** 或 **阿里巴巴普惠体**，两者都允许免费商用。

### 4. 标题 logo

- 现状：`Assets/Resources/title.png`，140×16 像素字，纯白 + 透明（亮色主题下会被压成深灰）。
- 已生成替代：`tools/make_logo.py` → 同规格的 **SUBSTRATA** 像素字。
- 开屏画面（背景、构图、动画）保持不变，只换这张图。
