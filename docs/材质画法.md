# 方块材质怎么画（像素风）

> 写给我自己看的工作手册，也是给"不会画"的人看的：这套流程不需要你会画画，
> 需要的是"按步骤判断"。每一步都有可检验的标准。

---

## 一、先声明一件事：这不是"画得精细"，是"放得对"

16×16 的方块只有 256 个像素。真正决定好看与否的不是细节，是三件事：

1. **明度结构**（哪块亮、哪块暗）——占七成
2. **形状语言**（团块还是直线）——占两成
3. **颜色**（色相偏移）——占一成

新手最容易犯的错是反过来：先在颜色上折腾，明度一片糊。

---

## 二、标准流程（美术都这么干）

### 第 1 步：定明度结构，只有三档

先在纸上/图里画 **亮 / 中 / 暗** 三块，比例大约 **1:6:3**：

- 中值占大头（约 60%）——它是"底色"，负责整体感；
- 暗部约 30%——负责形状和阴影，位置要**偏心**（别对称，对称就假）；
- 亮部不到 10%——只点几下，负责"有光"。

判断标准：**把图缩到 16×16 眯眼看，还能看出明暗分布**，这一关就过了。

### 第 2 步：定形状语言

| 材质类型 | 形状 | 例子 |
|---|---|---|
| 自然、松散 | 不规则团块（2~4 px），边缘毛糙 | 土、石、沙、砾 |
| 人工、规整 | 直线、直角、等距重复 | 砖、木板、格栅、地砖 |
| 流体 | 横向波纹、竖向拉长 | 水、岩浆 |

**关键：同一块里只用一种语言**。又想团块又想直线，就会像"贴了两张图"。

### 第 3 步：加"事件"

一块贴图里放 **3~5 个视觉事件**就够，多了必脏。事件指的是：

- 一条裂纹（2~4 px，**短而断**，不能横贯全图）
- 一个缺口 / 掉角
- 两三个不同深浅的色斑
- 一根草叶、一道木纹

位置要**偏**：别放正中，别平均分布。

### 第 4 步：上色（色相要偏移，不是单纯压暗）

这是"看着脏"和"看着润"的分界线：

```
阴影：明度降，同时色相往冷/紫偏一点
亮部：明度升，同时色相往暖/黄偏一点
```

单色压暗必发灰。举个实际数字（石）：

| 档 | RGB | 说明 |
|---|---|---|
| 亮 | 170,170,178 | 略偏冷 |
| 中亮 | 152,152,160 | |
| 中 | 132,132,142 | 比中间值再冷一点点 |
| 中暗 | 112,114,126 | 开始偏蓝 |
| 暗 | 92,96,112 | 明显偏蓝紫 |

注意每一档的**蓝通道都在涨**，红绿涨得慢——这就是"冷阴影"。

### 第 5 步：两个必做的检查

1. **100% 视图**：放大到 10 倍看细节，缩回 1 倍看整体。只在一个尺寸上看，一定翻车。
2. **3×3 平铺**：把这块复制 9 份拼起来。**边缘接不上、出现明显网格**，就是失败。
   这一步外部工具（AI、程序化）最容易忽略，手画的人也会忘。

---

## 三、会画的人真正在做的事

不是"画得像"，而是**做减法**：

- 先做一堆，然后删掉 80% 的细节，只留读得出来的那几个；
- 反复切到 1 倍视图，问自己"这块是什么材质？"——三秒内答不出来就重做；
- 同一套里的方块互相对比：石的明度、沙的明度、土的明度必须拉开档次，
  否则摆在墙上会分不清。

**材质之间靠明度区分，材质内部靠形状区分。** 这句话能解释 90% 的"看起来乱"。

---

## 四、我们的落地方式

1. 我先出 **三值草稿**（只有黑白灰三档，没有颜色）——这一步只判断"结构对不对"，
   你不需要懂画，只需要回答"这块像不像石头"；
2. 结构过了再上色（按上面的色相偏移表）；
3. 出 3×3 平铺图，一起看接缝；
4. 一次只做一种材质，做完定稿再下一个。

这样把"审美判断"和"技术执行"拆开了：你只需要判断像不像，画由我来。
