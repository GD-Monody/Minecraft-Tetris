# 我的世界俄罗斯方块 3D 版

## 这是什么

2022 年 B 站 UP 主「马克杯MarkCup」做过一个 MC 版俄罗斯方块（TetrisM），已经下不到了。这个项目是做新的版本：保留 MC 方块外观和方块特性，场地换成真正的 3D 网格。

## 当前状态

准备阶段。设计规格和技术方案是 v0.1，目标是先做出能玩的 v0.1：放置方块、z = 1、能消除、有音效。

## 目录

- `Assets/`：Unity 工程资源
  - `Art/Blocks/`：51 张方块贴图（16×16），以及脚本拼出的图集 `atlas.png`
  - `Art/Sfx/`：13 个 MC 音效
  - `Scenes/`：场景
  - `Scripts/`：代码
- `docs/`：设计规格、技术方案、任务清单
- `tools/`：构建脚本（图集拼接等）
- `ProjectSettings/`、`Packages/`：Unity 工程配置

## 怎么打开

用 Unity 2022.3.62f3c1 打开本目录。
